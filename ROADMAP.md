# 🗺️ Roadmap

**AI Skills Bank** grows with its community. Here is where the project is heading next.

## Current release — **v1.0**
- 500 skills across 10 categories
- Ready-to-use configs for 6 AI coding CLIs (Claude Code, Codex CLI, Gemini CLI, Kimi CLI, Aider, Cline)

## Next — **v1.1** *(in progress)*
- 📦 Machine-readable `skills.json` index ([good first issue](https://github.com/Ayanzadeh93/Claude-Skills-Bank/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22))
- 🤖 GitHub Actions CI to validate skill ID uniqueness and format
- 🖼 Animated demo + improved banner

## Later — **v1.2**
- 🔌 New platform adaptations (Cursor, Windsurf, GitHub Copilot CLI — contributions welcome!)
- 🧠 One **prompt example** per skill, starting with the Writing & Editing category

## Exploring
- 🌐 Searchable GitHub Pages catalog with filters
- 🌍 Community translations of the README
- 🔗 Integration guides for common agent frameworks

## Contributing

Want to help? Open a pull request, or browse [`good first issue`](https://github.com/Ayanzadeh93/Claude-Skills-Bank/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) tickets that don't need deep repo knowledge.

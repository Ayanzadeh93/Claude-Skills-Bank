# Security Policy

## Supported Versions

We support the latest release on the default branch.

| Version | Supported |
| ------- | --------- |
| 2.x     | ✅        |
| < 2.0   | ❌        |

## Reporting a Vulnerability

Please do not open public issues for security reports.

Instead, use GitHub Security Advisories to report vulnerabilities:
- Go to the **Security** tab in this repository.
- Click **Report a vulnerability** and follow the instructions.

We aim to acknowledge reports within 72 hours and will keep you updated as we
investigate and resolve the issue.

# Support

Thanks for using AI Skills Bank! Here’s the best way to get help:

## 📌 Where to Ask

- **Bugs or errors**: Open a GitHub issue using the bug report template.
- **Feature requests or new skills**: Open an issue using the feature request template.
- **Questions**: Start a discussion if available, or open an issue with the `question` label.

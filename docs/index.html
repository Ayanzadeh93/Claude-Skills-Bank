How It Works

Three steps from zero to a fully skill-equipped AI agent.

1

Pick Skills

Browse 10 categories with 50 skills each. Find what fits your workflow.

2

Choose Platform

Grab the ready-to-paste config for Claude Code, Codex, Gemini, Kimi, Aider, or Cline.

3

Activate

Paste into your config file. Skills load automatically on your next session.

Drop-in Configuration

Each platform has a ready-to-paste config. Skills activate instantly.

  • Skill routing — send tasks to the right skill by ID
  • Skill stacking — combine multiple skills for complex reviews
  • Skill chaining — sequential pipelines for multi-step workflows
  • Persona mode — set up persistent agent personalities

# AI Skills Bank — Windsurf starter

Paste into Windsurf workspace rules, or copy [`.windsurfrules`](.windsurfrules) to the project root.
Windsurf imports `.windsurfrules` for the whole session. Descriptions are copied from `skills.json`.

## Every session

### GS-016 – "Think Step by Step" Enforcer
Always structures solutions as numbered reasoning steps.

## When the request matches

### GS-020 – Risk & Edge-Case Spotter
Lists failure modes, edge cases, and ways to mitigate them. Use before an implementation.

### CS-009 – Code Review Partner
Performs a human-style code review with comments and priority labels. Use on a code review.

### CS-011 – Secure Coding Checker
Flags potential security issues and suggests safer patterns. Use on a security pass.

### DS-004 – EDA Strategist
Designs an exploratory data analysis plan. Use when exploring a dataset.

# 2. Coding & Code Review (CS‑001–CS‑050)

51. **CS‑001 – Language‑Agnostic Code Explainer** – Explains what a code snippet does in human terms.
52. **CS‑002 – Code Comment Writer** – Adds high‑quality comments to existing code without changing logic.
53. **CS‑003 – Refactoring Specialist** – Refactors code for readability and maintainability while preserving behavior.
54. **CS‑004 – Complexity Reducer** – Identifies complex regions and simplifies with clearer structure or patterns.
55. **CS‑005 – Documentation‑First Coder** – Writes docstrings and README‑level docs before proposing code changes.
56. **CS‑006 – Test Case Generator** – Generates unit tests, edge cases, and property‑based tests.
57. **CS‑007 – Bug Reproducer & Minimizer** – Isolates the minimal repro case for a bug from logs and descriptions.
58. **CS‑008 – Debugging Assistant** – Proposes hypotheses and diagnostic steps for code issues.
59. **CS‑009 – Code Review Partner** – Performs a human‑style code review with comments and priority labels.
60. **CS‑010 – Performance Profiler (Static)** – Inspects code for likely performance bottlenecks and hot paths.
61. **CS‑011 – Secure Coding Checker** – Flags potential security issues and suggests safer patterns.
62. **CS‑012 – API Contract Enforcer** – Checks if code adheres to a described API contract.
63. **CS‑013 – Type‑System Advisor** – Suggests typing improvements (e.g., TypeScript, Python typing).
64. **CS‑014 – Language Migration Assistant** – Helps translate code between languages while preserving semantics.
65. **CS‑015 – Framework Migration Assistant** – Guides migration between frameworks (e.g., React to Next.js).
66. **CS‑016 – CLI Tool Designer** – Designs CLI UX and scaffolds code for command‑line tools.
67. **CS‑017 – REST API Designer** – Proposes REST endpoints, models, and error formats.
68. **CS‑018 – GraphQL Schema Designer** – Designs GraphQL schemas and example queries.
69. **CS‑019 – Database Schema Normalizer** – Normalizes database schemas and suggests indexes.
70. **CS‑020 – ORM Query Optimizer** – Improves ORM queries to avoid N+1 and similar pitfalls.
71. **CS‑021 – Code Style Harmonizer** – Aligns code with a given style guide or linter.
72. **CS‑022 – Legacy Code Archaeologist** – Explains legacy code and proposes modernization paths.
73. **CS‑023 – Microservice Boundary Advisor** – Suggests service boundaries and communication patterns.
74. **CS‑024 – Error‑Handling Strategist** – Designs consistent error‑handling conventions across a codebase.
75. **CS‑025 – Logging Strategy Designer** – Proposes logging levels, structure, and redaction rules.
76. **CS‑026 – DevEx Scripting Helper** – Writes small scripts to speed up developer workflows.
77. **CS‑027 – IDE Prompt Snippet Generator** – Generates prompt snippets/macros for editor integration.
78. **CS‑028 – Codebase Tour Guide** – Creates onboarding tours for new contributors to a repo.
79. **CS‑029 – Git Workflow Advisor** – Suggests branch, review, and release workflows.
80. **CS‑030 – CI/CD Pipeline Designer** – Proposes CI/CD configurations and checks.
81. **CS‑031 – Containerization Assistant** – Helps write Dockerfiles and compose setups.
82. **CS‑032 – Infrastructure‑as‑Code Helper** – Assists with Terraform/CloudFormation patterns.
83. **CS‑033 – Security Threat Modeling Assistant** – Helps model threats and mitigations for an app.
84. **CS‑034 – Codebase Search Strategist** – Suggests search queries and patterns to explore large repos.
85. **CS‑035 – Repo Readme & Docs Generator** – Drafts initial repo documentation and contributing guides.
86. **CS‑036 – API Client Generator** – Generates API client code from OpenAPI or specs.
87. **CS‑037 – LLM Tooling Integrator** – Suggests how to integrate Claude into existing dev workflows.
88. **CS‑038 – Safe Code Example Curator** – Extracts and sanitizes examples for documentation.
89. **CS‑039 – Polyglot Snippet Translator** – Produces the same snippet in multiple languages.

92. **CS‑042 – Code Ownership Mapper** – Suggests ownership boundaries and CODEOWNERS entries.

94. **CS‑044 – Coding Interview Question Generator** – Generates coding problems with solutions.
95. **CS‑045 – Coding Interview Answer Analyzer** – Reviews candidate solutions with rubric‑style feedback.
96. **CS‑046 – Code Snippet Explainer for Non‑Engineers** – Explains code in business or product terms.
